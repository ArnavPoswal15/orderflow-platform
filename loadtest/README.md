Install [k6](https://k6.io/docs/get-started/installation/) (`brew install k6` on macOS). Start the full stack with `docker compose up --build`, then run `k6 run loadtest/orders.js` from the repo root. The script resets `LASTITEM` stock, races concurrent `POST /api/orders`, and fails the run if inventory goes negative or more than `INITIAL_STOCK` orders confirm. Paste the stdout summary and `OVERSOLD_CHECK` line into `docs/benchmarks.md`.
